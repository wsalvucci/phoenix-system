# Dashboard asset measurements

Assets built from the token colors in A1–A9. Ratios use the worst sampled opaque pixel; transparent margins are excluded. SVG artwork is `currentColor` and takes its contrast from CSS. The stage WebP tiles are lossless so opposite edges match exactly after encoding.
